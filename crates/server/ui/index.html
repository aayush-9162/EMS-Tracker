Block a site

A block reaches each computer at its next check-in (every 5 minutes unless changed under Settings). From then on the site no longer opens there, and a tab already showing it is closed. Unblocking works the same way: it takes effect at the next check-in. Computers that are switched off apply the change when they next start.

New organisation

Each client company is an organisation. Enter its name and an installer is made for it alone: every computer that installer is run on appears under this organisation. Its computers, blocked sites, blacklist words, categories, settings and reports are kept apart from every other organisation's.

Organisations

NameComputersOnlineAgentCreated

To rename an organisation, edit its name and press Enter. Installed computers are not affected by a rename.

Update the agent on all computers

To release a new version, choose the new ems-agent.exe and confirm with your password. Each computer downloads it at its next check-in, checks it and restarts itself on it. The same program goes to every organisation, and every computer stays in its own organisation: which organisation a computer belongs to is stored on that computer, not in the program, so an update cannot move or mix computers. To hold one organisation back, turn automatic updates off in its Settings first.

New user

Create a login for someone who helps manage organisations. You (an owner) see and manage everything; a member can reach only the organisations you grant, and only do what you allow there. Give access with "Edit access" after creating the user.

Tracking

Between check-ins activity is kept on the computer and the server is not contacted. Each check-in uploads it and picks up changes to blocking and settings. A shorter interval applies changes sooner; a longer one means fewer requests to the server.

Blocking

Leave this off unless you need it. With it on, Chrome, Edge, Brave and Firefox refuse blocked sites themselves, even if the agent's tray helper is stopped. The cost: an open browser takes up to 15 minutes to notice a change, so a site stays blocked that long after you unblock it or remove the agent, and the browser shows "managed by your organization".

Agent updates

When the server holds a newer agent, each computer downloads it at its next check-in, checks it, and restarts itself on it. Nobody has to visit the computer. Turn this off to keep this organisation on the agent it has. A new version is released on the Organisations page.

Data

Deletes this organisation's recorded website and application activity (and the blocked-attempt and word-hit logs) right now. Blocked sites, blacklist words, categories and computers are kept. Automatic deletion still follows the days above.

This installer is made for . Run it on each of its computers: it asks Windows for permission, installs itself and starts reporting. There is nothing to type, and the computer appears under Computers for this organisation by its name.

Save this settings file, made for , in the same folder as ems-agent.exe, then double-click ems-agent.exe on each computer. It asks Windows for permission, installs itself and starts reporting.

To get a single ready-made installer here instead, copy ems-agent.exe into the server's data folder.

Report API key

A read-only key for scripts that fetch this organisation's reports, sent as Authorization: Bearer <key>. It cannot read any other organisation.
